2. WordPress側の設定

1

パーマリンク設定

WordPress管理画面 → 設定 → パーマリンク

カスタム構造を選択し、以下を入力：

/news/%postname%/

これでお知らせ記事が vaizo.jp/news/記事名/ のURLになる。

2

フロントページ設定

WordPress管理画面 → 設定 → 表示設定

  • 「ホームページの表示」→ 固定ページを選択
  • 「ホームページ」→ 空の固定ページを作成して選択（表示されないので名前は何でもOK）
  • 「投稿ページ」→ なし（または「お知らせ」固定ページを作成）
重要: これをしないとWordPressのトップページが静的 index.html を上書きしてしまう。
3

テーマのカスタマイズ

WordPressの記事ページをVAIZOサイトのデザインに合わせるため、子テーマを作成する。

必要なファイル:

  • style.css — VAIZOのデザインシステムを適用
  • single.php — 個別記事テンプレート（VAIZOヘッダー/フッター付き）
  • archive.php — 記事一覧テンプレート
  • functions.php — セキュリティ設定・不要機能の無効化

→ テーマファイルはSSHでアップロードする。

4

セキュリティ強化

functions.php に以下を追加：

// XML-RPC無効化（ブルートフォース攻撃対策）
add_filter('xmlrpc_enabled', '__return_false');

// REST API を認証済みユーザーのみに制限（公開投稿の取得は許可）
add_filter('rest_authentication_errors', function($result) {
    if (!is_user_logged_in() && !is_admin()) {
        // 公開コンテンツの取得は許可
        if (isset($_SERVER['REQUEST_METHOD']) && $_SERVER['REQUEST_METHOD'] === 'GET') {
            return $result;
        }
        return new WP_Error('rest_not_logged_in', 'Authentication required', array('status' => 401));
    }
    return $result;
});

// バージョン情報を隠す
remove_action('wp_head', 'wp_generator');

// 絵文字スクリプト無効化（パフォーマンス）
remove_action('wp_head', 'print_emoji_detection_script', 7);
remove_action('wp_print_styles', 'print_emoji_styles');

設定手順

  1. ユーザー名・メールアドレスを入力

  3. 「新規ユーザーを追加」をクリック
  4. ※ ログインURLはセキュリティプラグインでカスタム化済み

4. AI記事自動生成の仕組み

方法A: Claude Code + WordPress MCP（推奨）

Claude Code から直接WordPressに下書き投稿する。

WordPressに下書きとして投稿してください。

テーマ: AIエージェントを活用した業務改善の最新事例

5. 静的サイトとの統合

.htaccess の設定

静的HTMLファイルが存在するパスは静的ファイルを配信し、/news/ 配下はWordPressが処理するように設定。

# 静的ファイル → 直接配信（既存の動作）
# /news/ → WordPress が処理
#
# 現在の .htaccess の WordPress セクションが
# 自動的にこの振り分けを行う:
#   RewriteCond %{REQUEST_FILENAME} !-f  ← ファイルが存在しなければ
#   RewriteCond %{REQUEST_FILENAME} !-d  ← ディレクトリが存在しなければ
#   RewriteRule . /index.php [L]         ← WordPress に渡す
必要な作業: 現在 /news/ に静的HTMLファイルが存在するため、これらを削除またはリネームする必要がある。WordPressが /news/ を処理できるようにするため。

実行コマンド

# 既存の静的ニュースファイルをバックアップして削除
ssh -i ~/.ssh/xserver_vaizo.key -p 10022 home@sv2.xwp.ne.jp \
  "cd home.xwp.jp/public_html && \
   mkdir -p _backup_news && \
   mv news/ _backup_news/ && \
   echo 'Done'"

ヘッダーナビのリンク

静的HTMLのヘッダーにある「お知らせ」リンクはそのまま /news/ を指しているので変更不要。WordPressが /news/ を処理するようになれば自動的につながる。

7. 日常運用フロー

記事作成（誰でも・どこからでも）

  1. ブラウザで vaizo.jp/wp-admin/ にログイン
  2. 「投稿」→「新規投稿を追加」
  3. AI生成 or 手動で記事を作成
  4. 「プレビュー」で確認 →「公開」

AIで記事を一括生成する場合

  1. Claude Code を起動
  2. 「今週のお知らせ記事を3本作成して、下書きで投稿して」と指示
  3. WordPress MCPが自動で下書き投稿
  4. 各メンバーが wp-admin でレビュー・公開
