1. エグゼクティブサマリー

1.1 本書の目的

G-LINE 採用サイトに設置する AI チャットボットの要件・設計・仮決定事項を一元的にまとめたものです。ヒアリング結果、業界標準、法的要件（APPI / GDPR）、コスト制約を踏まえ、「社長の分身として応募者に答える」体験を、安全・保守しやすく・拡張可能な形で実装するための仕様書です。

1.2 ゴール

軸目標
主目的会社理解 → 応募・面接予約への誘導
副目的応募前の不安解消 / 会社への興味喚起 / 接点強化
成功指標応募転換率 5% / エスカレーション率 20% 以下 / RAG ヒット率 80% 以上
公開予定2026年6月1日（仮）

2. プロジェクト目的と背景

2.1 背景

  • 採用市場の競争激化により、応募前の会社理解が応募転換率を大きく左右する
  • 営業時間外にも問い合わせ機会がある一方、人的対応にはコスト上限がある
  • 代表（荒牧氏）の熱意ある人物像が会社の魅力そのものだが、全員に直接語れない
  • AI 技術の成熟により、代表の分身としての対応が現実的な品質に到達

2.2 主目的（再掲）

  1. 会社理解を深めてもらい、そのまま応募・面接予約につなげる
  2. 応募前の不安解消
  3. 会社への興味喚起
  4. ホームページ上での接点強化

2.3 やらないこと（非ゴール）

  • 何でも答える万能AI（範囲を厳格に限定）
  • 個別の給与交渉・条件交渉
  • 未公開情報・機密情報の開示
  • 競合他社との比較論

6. アーキテクチャ設計

6.1 全体構成図

┌─ [顧客サイト（G-LINE HP 等、どのサーバーでも可）]
│   HTML に <script src=".../widget.js" data-tenant="g-line-001" async></script>
│                          ↓ CORS fetch
├─ [フロント配信] Cloudflare Pages（無料・CDN・日本エッジ）
│   widget.js (Preact, 20KB gz) + widget.css + iframe.html
│                          ↓ REST API
├─ [API サーバー] Cloudflare Workers（無料枠 10万req/日）
│   /api/chat /api/apply /api/event /api/gdpr
│   + LLM Adapter（Gemini/OpenAI/Anthropic 切替可能）
│   + Guardrail 層（禁止トピック検知）
│   + 会話ログ匿名化
│                          ↓ Hyperdrive（コネクションプール）
├─ [データベース] AWS RDS PostgreSQL（東京 ap-northeast-1）
│   db.t4g.micro / 20GB / pgvector 拡張
│   └─ applicants / appointments / conversations / rag_chunks / faq / events / escalations
│                          ↕
└─ [外部連携]
    ├─ Gemini API（LLM + 埋込）
    ├─ Resend（info メール通知、無料 3000通/月）
    ├─ Slack Webhook（運用通知）
    └─ GitHub Actions（週次監視・日次削除・月次RAG再構築）

6.2 データフロー（チャット1ターン）

  1. ユーザーがチャットに質問を入力
  2. ウィジェット → Cloudflare Workers `/api/chat` へ POST
  3. Workers がガードレール層でNGトピック判定。NG なら即エスカレーション文言を返却
  4. OK なら質問を Gemini embedding に送り、768次元ベクトル化
  5. RDS pgvector で Top5 類似チャンク検索
  6. システムプロンプト + RAG結果 + 会話履歴 を Gemini 3.1 Flash-Lite に送信
  7. Gemini の応答を匿名化ログ保存 + ユーザーに返却
  8. 応募意志が読み取れれば応募フォーム URL を提示

9. セキュリティ・コンプライアンス

9.1 認証・暗号化

  • 保存時：AES-256（AWS KMS で鍵管理、年1回ローテーション）
  • 通信時：TLS 1.2/1.3、SSL verify-full
  • 個人情報列：pgcrypto の pgp_sym_encrypt でアプリ層暗号化
  • 暗号化鍵：AWS Secrets Manager で一元管理
  • API キー：GitHub Secrets + Cloudflare Workers Secrets

9.2 認証・認可

  • 管理画面：AWS IAM Identity Center（SSO）または Cloudflare Access
  • Workers → RDS：IAM データベース認証（12時間トークン）
  • ウィジェット：テナントID + Origin 検証 + CORS allowlist
  • レート制限：IP単位 + テナント単位の二重制限（Cloudflare WAF）

9.3 APPI（個人情報保護法）対応

要件対応
個人情報の利用目的明示プライバシーポリシー改訂、応募フォームで同意取得
安全管理措置暗号化・RLS・アクセスログ・90日削除
越境移転東京リージョン保管 → 越境移転なし
開示・訂正・削除請求info メール経由、7日以内受付 → 30日以内処理

クレーム・誹謗中傷即エスカレーション、担当者が個別対応
プロンプトインジェクション応答拒否 + エスカレーション
応募と無関係な雑談軽く受け止めるが深入りしない
恋愛・人生相談等温かく受け止め、採用の話題に戻す
