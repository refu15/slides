- **サービス名**: G-LINE 採用チャットボット（仮）

## 背景情報

### 技術的セキュリティ対策（既実施）
- AES-256 at rest（AWS KMS）、TLS 1.2+ in transit
- pgcrypto による個人情報列暗号化
- PostgreSQL Row Level Security（ロール分離3段階）
- 90日 TTL 自動削除 + GDPR cascade 削除
- Cloudflare Rate Limiting / Turnstile
- 監査ログ（audit_log）で全 PII 操作を記録
- 年1回のペネトレーションテスト予定

### コンプライアンス認証（利用インフラ）
- AWS: SOC 2 Type 2 / ISO 27001 / ISMAP / FISC 対応済み
- Cloudflare: SOC 2 Type 2 / ISO 27001 / FedRAMP 対応済み
- 両社とも東京/大阪リージョンあり
