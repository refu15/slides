## 🔐 機密保持

- 本書群には **個人情報のサンプル**は含まれていません（全て架空）
- ただし、**企業の体制・連絡先**を含むため、第三者共有は禁止
- レビュー完了後、弁護士事務所側での保管期間は**貴事務所の規程に準拠**
- G-LINE 側では **10年間保管**します（商法 522条に基づく）
