# 個人情報漏洩 緊急対応計画書

個人情報保護法（APPI）の漏洩報告義務（施行規則第7条の3）および GDPR 第33条・34条の遵守を目的とした、漏洩検知から報告までの緊急対応プラン。

**最重要**: 漏洩を知った時点から起算して **72時間以内** に個人情報保護委員会（PPC）へ報告する義務がある。

---

## 🚨 漏洩検知時の初動（60分以内）

### Step 1: 確認と封じ込め（15分以内）

```
[検知] ↓
 ├─ Sentry アラート
 ├─ 採用担当が不審な挙動を発見
 ├─ 応募者から指摘
 ├─ 外部（研究者・SNS）から通報
 └─ Slack #gline-ops でアラート
```

- [ ] **即座に代表・開発事業者へ Slack / 電話で通報**（SLA: 30分以内）
- [ ] 「漏洩疑い」と明記（確定前でも報告）
- [ ] 一時的にシステムを停止するか判断
  - PII 継続漏洩の恐れあり → **Workers を即停止**: `npx wrangler delete --env production` or Cloudflare Dashboard で disable
  - 限定的・封じ込め可能 → 該当経路のみ遮断（CORS 変更・rate limiter 強化）

### Step 2: 影響範囲の特定（30分以内）

- [ ] `audit_log` テーブルで異常アクセスを特定
- [ ] `conversations` / `applicants` テーブルでアクセス履歴調査
- [ ] Cloudflare Workers Tail ログを過去72時間分保全
- [ ] AWS RDS CloudTrail で異常クエリを確認
- [ ] 漏洩した可能性のあるデータを列挙：
  - [ ] 氏名 / メール / 電話 / 希望日時
  - [ ] 会話ログ（匿名化済みだが、session_id と組み合わせた情報）
  - [ ] その他（具体的に）
- [ ] 影響人数を推定

### Step 3: 関係者への第一報（60分以内）

以下へ即時連絡:
- [ ] 代表（荒牧氏）
- [ ] 採用担当
- [ ] 開発事業者 担当者
- [ ] 必要に応じて法律顧問

---

## 📋 72時間以内に実施する事項

### PPC（個人情報保護委員会）への報告（必須）

APPI 施行規則第7条の3に基づく報告:

**報告経路**:
- PPC 報告フォーム: https://roueihoukoku.ppc.go.jp/
- 電話（緊急時）: 03-6457-9680

**報告内容（必須項目）**:
1. 事業者名・連絡先
2. 漏洩事案の概要
3. 漏洩した個人データの項目（氏名・メール等）
4. 漏洩した件数
5. 原因
6. 二次被害の有無・可能性
7. 本人への通知状況・予定
8. 公表状況・予定
9. 再発防止策

**テンプレート**:
```
1. 事業者名
  株式会社 G-LINE
  住所: [住所]
  連絡先: info@g-line.co.jp

2. 事案概要
  2026年MM月DD日HH時頃、採用チャットボット（gline-bot.example.jp）で
  [原因]により、応募者の個人情報が漏洩した可能性が判明した。

3. 漏洩データ項目
  氏名、メールアドレス、電話番号、面接希望日時

4. 件数
  最大 N 名分（調査中）

5. 原因
  [具体的な技術的原因]

6. 二次被害
  現時点で二次被害の報告なし / ○○の可能性あり

7. 本人通知
  MM月DD日に該当者全員へメール通知予定

8. 公表
  G-LINE 公式サイトおよびプレスリリースで公表予定

9. 再発防止策
  [短期・中期・長期の対策]
```

### 本人通知

APPI 第26条に基づく本人通知:
- [ ] 漏洩した本人への通知メール送信（下記テンプレート）
- [ ] 大規模漏洩（500名超）の場合は公表も検討

**本人通知メールテンプレート**:
```
件名: 【重要】個人情報漏洩に関するお詫びとご報告

[応募者名] 様

平素より G-LINE の採用活動にご関心をお寄せいただき、誠にありがとうございます。

このたび、弊社採用チャットボットにおきまして、お客様の個人情報が
第三者に漏洩した可能性があることが判明いたしました。
心よりお詫び申し上げます。

【漏洩した情報】
- 氏名
- メールアドレス
- 電話番号
- ご希望日時

【漏洩期間】
2026年MM月DD日 HH:MM 〜 2026年MM月DD日 HH:MM

【原因】
[原因を記載]

【現在の対応】
- 漏洩経路を既に遮断済み
- 個人情報保護委員会へ報告済み
- 再発防止策を実施中

【お客様へのお願い】
該当期間にご登録いただいたメールアドレス・電話番号に不審な連絡があった
場合は、弊社までご一報ください。

重ね重ねお詫び申し上げます。
今後このようなことが起こらぬよう、体制強化に努めてまいります。

[日付]
株式会社 G-LINE
代表取締役 荒牧
```

### 公表判断

- 500名超 / 不正目的（第26条 2項）→ **公表必須**
- それ以外 → 状況に応じて判断
- 公表媒体: G-LINE 公式サイト（目立つ位置）、必要に応じて記者会見

## 🔐 30日以内に実施する事項

### 最終報告書の PPC 提出

- [ ] 追加調査結果の反映
- [ ] 最終的な被害件数の確定
- [ ] 原因の確定と技術的詳細
- [ ] 再発防止策の実施状況
- [ ] 次回監査計画

### 全被害者への本人通知完了

- [ ] 未到達メールへの再送
- [ ] 電話連絡（メール未到達者）
- [ ] 通知完了率 100% を目指す

### 再発防止策の実施

技術的対策:
- [ ] 脆弱性修正デプロイ
- [ ] コードレビュー強化（security-auditor エージェント活用）
- [ ] 追加監査ログ設置

組織的対策:
- [ ] 関係者へのセキュリティ研修
- [ ] 規程・マニュアル改訂
